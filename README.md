# AI Interview Coach & Career Preparation System

## About the Project
AI Interview Coach is a web-based interview preparation platform designed to help students and job seekers practice interviews, improve their answers, and prepare for career opportunities.

## Features
- Interview preparation workflow
- Interview setup based on role and difficulty
- Question-based practice
- Answer submission and evaluation
- Feedback and result summary
- Career preparation support

## Technology
- HTML
- Web technologies used in the project
